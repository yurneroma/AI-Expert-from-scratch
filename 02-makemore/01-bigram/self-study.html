1. 为什么要让模型预测下一个字符

1.1 我们想做一个怎样的程序

假设手里有一份名字列表，希望程序生成一些具有相似拼写习惯的新名字。

一种办法是从列表随机取一个名字。它可以复现训练样本，却没有学会如何组合字符。另一种办法是每次均匀随机选字母，拼写通常没有训练数据中的规律。

我们希望程序介于两者之间：保留从数据里学到的局部规律，又允许重新组合。

生成可以一步一步进行：

  1. 根据开头的规律，选第一个字符。
  2. 根据已经生成的内容，选下一个字符。
  3. 重复，直到决定结束。

于是，“生成名字”变成了一个会反复调用的小任务：给定已有内容，为每一种可能的下一个字符分配概率。

例如，模型看到 a 后，可能给出：

下一个是 . ：0.2    （结束）
下一个是 a ：0.3
下一个是 b ：0.5

这三个数非负，而且加起来等于 1。这叫一个分类概率分布，也叫 categorical distribution。这里的数字只是示意，稍后会从真实计数算出来。

1.2 为什么输出一组概率，而不只输出一个答案

相同的前缀可以有多种合理续写。只记“最可能是 b”，会丢掉其他可能性和不确定程度。

有了整组概率，我们可以完成不同任务：

  • 生成：按照这组概率抽一个字符，而不是永远选概率最大的字符。
  • 评分：判断模型给真实出现的字符分配了多少概率。
  • 训练：如果真实字符的概率太低，就调整模型。

后面出现的计数、softmax、NLL，都是在服务这些需求。

1.3 这里的 token 到底是什么

token 是模型处理的离散单位。本 Lab 中，一个字母就是一个 token，另加一个表示边界的特殊 token .。

“bigram”中的 bi 表示相邻的两个 token。一个用于输入，一个作为预测目标。因此 bigram 是“用前一个预测下一个”，而不是“输入前两个预测第三个”；后者叫 trigram。

教材经常用单词作为 token，本 Lab 用字符。概率建模方法可以沿用，但两种模型能利用的信息不同。

2. 概率补课：整段文字与下一步预测怎样连起来

这一节解决一个根本问题：我们关心完整字符串，为什么只训练“预测下一个”就有意义？

2.1 条件概率表示缩小观察范围

记号

P(b∣a) P(b\mid a)

读作：“在当前字符已经是 a 的条件下，下一个字符是 b 的概率。”竖线右边是已知条件，左边是要预测的事件。

假设有 100 次转移，其中 20 次以 a 为当前字符，这 20 次里有 5 次下一个是 b。那么经验比例是：

P̂(b∣a)=520=0.25. \widehat P(b\mid a)=\frac{5}{20}=0.25.

分母是 20，不是 100。因为问题已经把范围限制在“当前字符是 a”的情况。上面的帽子表示这是根据数据做出的估计，未必等于未来数据的真实概率。

2.2 概率的乘法规则来自哪里

对两个事件 A,BA,B，当 P(A)>0P(A)>0 时，条件概率定义为：

P(B∣A)=P(A,B)P(A). P(B\mid A)=\frac{P(A,B)}{P(A)}.

这里 P(A,B)P(A,B) 表示两个事件一起发生的概率。把分母乘到左边：

P(A,B)=P(A)P(B∣A). P(A,B)=P(A)P(B\mid A).

再加入第三个事件 CC：

P(A,B,C)=P(A,B)P(C∣A,B)=P(A)P(B∣A)P(C∣A,B). \begin{aligned} P(A,B,C) &=P(A,B)P(C\mid A,B)\\ &=P(A)P(B\mid A)P(C\mid A,B). \end{aligned}

每一步都只是再次使用条件概率定义。推广到任意长度，这就是概率链式法则。

这里没有假设各个字符独立。事实上，条件里保留了前面发生的事情。它也不是 micrograd 中用于求导的链式法则；两个名字相似，处理的问题不同。

2.3 用一个字符串展开

先临时用 BOS 表示开始，EOS 表示结束。一个名字 ab 的完整生成事件是：从开始状态生成 a，再生成 b，然后结束。

P(a,b,EOS∣BOS)=P(a∣BOS)⋅P(b∣BOS,a)⋅P(EOS∣BOS,a,b). \begin{aligned} P(a,b,\mathrm{EOS}\mid\mathrm{BOS}) ={}&P(a\mid\mathrm{BOS})\\ &\cdot P(b\mid\mathrm{BOS},a)\\ &\cdot P(\mathrm{EOS}\mid\mathrm{BOS},a,b). \end{aligned}

因此，只要能计算每一步在真实前缀下的条件概率，就能把它们相乘，得到完整字符串的概率。 这就是下一步预测与整段文字建模的连接。

最前面的 BOS 是给定的起点，不需要额外乘一个“出现 BOS 的概率”。最后的 EOS 是模型要预测的事件，需要计入。

3. Bigram 的假设：为了能估计，先少看一点历史

3.1 完整前缀为什么难处理

如果每一种完整前缀都单独建一张统计表，前缀越长，可能的组合越多。训练数据中常常只出现一次，甚至从来没有出现。

例如，要估计“在 alexandr 后面接什么”，可以利用的样本很少；要估计“在 r 后面接什么”，可利用的样本多得多，但会混入其他前缀的情况。

bigram 选择后者：把历史压缩成最后一个 token。

P(ct∣c1,…,ct−1)≈P(ct∣ct−1). P(c_t\mid c_1,\ldots,c_{t-1}) \approx P(c_t\mid c_{t-1}).

这里 ctc_t 是第 tt 个字符。近似号表达的是建模选择，不是从概率链式法则推出的定理。这种只依赖当前状态预测下一步的设定称为一阶 Markov 假设。

代价很明确：前缀 ba 和 aa 最后都是 a，bigram 就必须为它们给出相同的下一字符分布。数据再多、训练再久，也无法让这个模型区分它们。

这是教材介绍 n-gram 的切入点：先解释完整历史的稀疏问题，再引出缩短条件的近似。参见 Jurafsky 与 Martin，第 3.1 节。

3.2 为什么要加入开始与结束

本 Lab 用同一个符号 . 表示边界：

名字 ab： . a b .
转移事件：(. → a), (a → b), (b → .)

. 作为输入时，表示从起点选择第一个字符；. 作为输出时，表示结束当前名字。

如果没有开始事件，模型无法从这份数据学到首字符分布。如果没有结束事件，模型无法学到何时停止，只能由程序在外部强行截断。

把开始和结束合用一个 token，是这个小实验的编码约定。它可行的原因是：生成时一旦抽到 . 就停止，不会再把这个结束事件送回去续写同一个名字。其他实现可以使用不同的 BOS 和 EOS，但词表与可允许转移也要一起调整。

长度为 LL 的名字会产生 L+1L+1 个转移：一条开始边、L−1L-1 条内部边、一条结束边。例如 ab 长度为 2，产生 3 个训练样本。

3.3 现在写出 bigram 的完整名字概率

用 c0=.c_0=. 表示起点，cL+1=.c_{L+1}=. 表示终点。模型参数统称为 θ\theta，可以是一张概率表，也可以是后面要学的权重矩阵。

Pθ(c1…cL 并结束)=∏t=1L+1Pθ(ct∣ct−1). P_\theta(c_1\ldots c_L\text{ 并结束}) =\prod_{t=1}^{L+1}P_\theta(c_t\mid c_{t-1}).

∏\prod 是连乘符号。例如对 ab，这个式子就是：

Pθ(𝚊𝚋)=Pθ(a∣.)Pθ(b∣a)Pθ(.∣b). P_\theta(\texttt{ab}) =P_\theta(a\mid .)P_\theta(b\mid a)P_\theta(.\mid b).

这里对已经选定的 bigram 模型写等号，因为这就是模型的定义。把它当作现实中完整语言分布的替代时，才是在做近似。

4. 贯穿例子：只用两个名字，把数据完全展开

后面除特别说明外，都使用：

words = ["ab", "aa"]

它足够小，可以在纸上核对每一项，也与本 Lab 的公开检查一致。

4.1 字符先变成编号

固定顺序为 .、a、b：

stoi = {".": 0, "a": 1, "b": 2}
itos = {0: ".", 1: "a", 2: "b"}
V = 3

stoi 是 string to integer，itos 是反向查询，VV 是词表大小。

编号只是查表地址。b=2 不表示 b 比 a=1 大一倍，也不表示字符间距离。把这些整数直接当连续数值特征会人为引入顺序含义；后面的 one-hot 正是为了明确它们是类别。

4.2 每个样本都是“当前字符、真实下一个字符”

ab：(. → a), (a → b), (b → .)
aa：(. → a), (a → a), (a → .)

展开成编号数组：

inputs  = [0, 1, 2, 0, 1, 1]
targets = [1, 2, 0, 1, 1, 0]

第 mm 个样本记作 (xm,ym)(x_m,y_m)，分别对应 inputs[m] 和 targets[m]。一共有 M=6M=6 个样本。

目标标签直接来自文本中真实的下一个字符，不需要人工再给每个样本标注答案。这是下一 token 预测提供监督信号的方式。

每个名字分别添加边界、分别拆样本。不要把 ab 和 aa 直接拼成 abaa，否则会捏造一个跨名字的 b → a，还丢掉真实边界。

5. 为什么“次数除以行总数”就是训练结果

我们需要把整数计数变成下一字符的概率。先从直觉入手，再说明它对应哪个优化目标。

5.1 在同一条件内计算比例

当前字符为 a 的三次观测中，后面分别是 b、a、.。如果暂时完全相信这三次观测，每种结果都应分得 1/31/3。

一般地，当 ni>0n_i>0 时：

Pij=P(j∣i)=Cijni=Cij∑k=0V−1Cik. P_{ij}=P(j\mid i)=\frac{C_{ij}}{n_i} =\frac{C_{ij}}{\sum_{k=0}^{V-1}C_{ik}}.

分母里的 kk 是一个遍历所有列的临时索引。分子固定目标列 jj，分母计算当前行所有可能去向的总数。

每行自然加起来等于 1：

∑jPij=∑jCijni=nini=1. \sum_j P_{ij}=\frac{\sum_j C_{ij}}{n_i}=\frac{n_i}{n_i}=1.

本例得到：

PMLE=(0101/31/31/3100). P_{\mathrm{MLE}}= \begin{pmatrix} 0&1&0\\ 1/3&1/3&1/3\\ 1&0&0 \end{pmatrix}.

行、列顺序始终都是 .、a、b。特别注意：整张表的和是 V=3V=3，不是 1，因为它包含三个不同条件下的概率分布。

5.2 什么叫似然

概率与似然可以用同一个计算式，区别在于我们把什么当作变量。

  • 已经给定模型，问“它产生这些数据的概率是多少”，是在给数据算概率。
  • 数据已经固定，比较“哪组参数让这些观测更容易发生”，是在比较参数的似然。

设一行的候选概率是 (p.,pa,pb)(p_.,p_a,p_b)。对当前字符为 a 的三个观测，候选行分配的似然是：

ℒa=pbpap.. \mathcal L_a=p_b\,p_a\,p_{.}.

因为观测中每种后继各出现一次。两组候选分布的对比是：

(1/3)3≈0.037037,0.8×0.1×0.1=0.008. (1/3)^3\approx0.037037, \qquad 0.8\times0.1\times0.1=0.008.

第二组虽然特别偏爱某一个字符，却让另外两个真实观测太难发生。因此它给整组观测的似然更低。

“最大似然估计”（maximum likelihood estimation，MLE）就是在所有合法概率分布中，找让固定训练数据的似然最大的一组参数。它没有承诺未来也最好；泛化要另行验证。

5.3 在 a 这一行亲手求一次最优解

由于概率和必须为 1，只需设 pa=u,pb=vp_a=u,p_b=v，剩下 p.=1−u−vp_.=1-u-v。要求 u>0,v>0,u+v<1u>0,v>0,u+v<1。

目标是最大化：

ℒa(u,v)=uv(1−u−v). \mathcal L_a(u,v)=uv(1-u-v).

先取自然对数。对数严格递增，所以最大值的位置不变；乘积会变成容易求导的和：

f(u,v)=log⁡u+log⁡v+log⁡(1−u−v). f(u,v)=\log u+\log v+\log(1-u-v).

分别对 u,vu,v 求偏导，令它们为零：

∂f∂u=1u−11−u−v=0,∂f∂v=1v−11−u−v=0. \frac{\partial f}{\partial u}=\frac1u-\frac1{1-u-v}=0, \qquad \frac{\partial f}{\partial v}=\frac1v-\frac1{1-u-v}=0.

第一式给出 u=1−u−vu=1-u-v，第二式给出 v=1−u−vv=1-u-v。三种概率相同，又必须和为 1，于是每种都是 1/31/3。

这确实是最大值：log\log 在正数上是凹函数，这个目标也是凹函数；边界上任意一种观测概率变成零，似然就变成零。

对开始行而言，观测只有两个 a，似然是 pa2p_a^2，最大值在 pa=1p_a=1。对 b 行，观测只有一个结束事件，最大值在 p.=1p_.=1。这样就得到上面的整张概率表。

6. 概率表怎样写成张量：dim 和 keepdim 的目的

这一节把已经明确的数学运算翻译成 PyTorch。代码应该服从“每行单独归一化”的含义。

import torch

C = torch.tensor([
    [0, 2, 0],
    [1, 1, 1],
    [1, 0, 0],
], dtype=torch.float64)

row_totals = C.sum(dim=1, keepdim=True)
P = C / row_totals

print(row_totals)  # [[2.], [3.], [1.]]，shape 为 (3, 1)
print(P)

对 (行, 列) 这个二维矩阵，dim=1 指定沿列方向求和，留下每一行的总数。keepdim=True 保留被求和的维度，让结果仍然是二维列向量 (V, 1)。

广播除法等价于：

(020111100)/(231)=(0/22/20/21/31/31/31/10/10/1). \begin{pmatrix}0&2&0\\1&1&1\\1&0&0\end{pmatrix} \mathbin{/} \begin{pmatrix}2\\3\\1\end{pmatrix} = \begin{pmatrix}0/2&2/2&0/2\\1/3&1/3&1/3\\1/1&0/1&0/1\end{pmatrix}.

广播会把每一行的那个分母用于该行的所有列。

如果写 C / C.sum(1)，分母的 shape 是 (3,)。PyTorch 从最右侧维度对齐，它会按列使用 [2, 3, 1]，得到诸如第二行 [1/2, 1/3, 1] 的错误结果。由于矩阵恰好是方阵，代码可能正常执行，却没有做你想要的数学运算。

广播的维度对齐规则可查 PyTorch 官方说明。

另一个常见错误是除以 C.sum()。它估计的是从所有转移里随机取一个时，某个二元组合占多少比例，不是固定当前字符后的条件概率。

检查重点：不要只看 shape 或“代码没报错”，要看 P.sum(dim=1) 是否每项都是 1，再抽一行手算。

7. NLL 的背景、推导和数值意义

现在已经有一个模型，接下来需要回答：怎样用一个数评价它？为什么训练里经常出现 -log？

7.1 从模型给真实数据的概率开始

用第 5 节的未平滑概率表：

P(𝚊𝚋)=1×13×1=13, P(\texttt{ab})=1\times\frac13\times1=\frac13,

P(𝚊𝚊)=1×13×13=19. P(\texttt{aa})=1\times\frac13\times\frac13=\frac19.

如果把两个名字看作模型的两次独立生成，训练数据的似然为：

ℒ=P(𝚊𝚋)P(𝚊𝚊)=13×19=127. \mathcal L=P(\texttt{ab})P(\texttt{aa}) =\frac13\times\frac19=\frac1{27}.

这里是对独立名字的概率相乘。单个名字内部各步可以通过条件概率相乘，不需要假设相邻字符彼此独立。

7.2 为什么取 log

一连串小于 1 的数相乘，会越来越小。比如 0.11000=10−10000.1^{1000}=10^{-1000}，超出了常用浮点格式可表示的非零范围。

自然对数把乘积变成和：

log⁡ℒ=log⁡∏m=1MPxm,ym=∑m=1Mlog⁡Pxm,ym. \log\mathcal L =\log\prod_{m=1}^{M}P_{x_m,y_m} =\sum_{m=1}^{M}\log P_{x_m,y_m}.

log 在本文都是自然对数，即以 ee 为底，PyTorch 的 torch.log 也如此。因为它严格递增，最大化似然和最大化 log-likelihood 是同一个优化目标。

如果对数运算生疏，先记住并理解：log⁡1=0\log 1=0，log⁡(ab)=log⁡a+log⁡b\log(ab)=\log a+\log b，且 0<p<10<p<1 时 log⁡p<0\log p<0。

7.3 为什么加负号，为什么再平均

训练代码通常采用“最小化 loss”的约定，所以把要最大化的 log-likelihood 取负号。

再除以预测事件总数 MM，得到平均负对数似然（average negative log-likelihood）：

LNLL=−1M∑m=1Mlog⁡Pxm,ym. \boxed{L_{\mathrm{NLL}}=-\frac1M\sum_{m=1}^{M}\log P_{x_m,y_m}}.

三个操作各有目的：

  1. 乘概率：评价模型给真实观测的联合解释。
  2. 取对数和负号：得到便于计算、便于最小化的目标。
  3. 除以 MM：报告每次预测平均付出的损失，方便在一致的统计口径下比较。

本例共有 6 次预测，包括开始和结束事件，因此：

LNLL=−16log⁡127=log⁡276=log⁡32≈0.549306. L_{\mathrm{NLL}} =-\frac16\log\frac1{27} =\frac{\log27}{6} =\frac{\log3}{2} \approx0.549306.

这里不是除以名字数 2，也不是除以正文字符总数 4。若不同名字长度不同，“先平均每个名字的平均 NLL，再平均所有名字”，也会改变长短名字的权重；本 Lab 采用所有转移等权。

7.4 单个 -log p 在惩罚什么

这里只看模型给真实下一个字符的概率 pp：

真实字符的概率 pp 单次损失 −log⁡p-\log p 含义
1 0 模型完全押中这个观测
0.5 0.693147 给真实结果一半概率
0.1 2.302585 对真实结果分配得很少
0.01 4.605170 对真实结果极不看好
0 +∞+\infty 模型认为实际发生的事不可能发生

模型越不看好真实结果，受到的惩罚越大。给真实结果的概率越高，损失越低。

这与准确率不同。两个模型都把 b 排第一，但一个给真实 b 的概率为 0.6，另一个为 0.99，准确率无法区分，NLL 可以。

7.5 为什么均匀分布的 NLL 是 log(V)

如果每种候选 token 都分到 1/V1/V，那么每个真实观测的损失都一样：

−log⁡(1/V)=log⁡V. -\log(1/V)=\log V.

把 MM 个相同值平均，仍然是 log⁡V\log V：

−1M∑m=1Mlog⁡(1/V)=−1MM(−log⁡V)=log⁡V. -\frac1M\sum_{m=1}^M\log(1/V) =-\frac1M\,M(-\log V)=\log V.

本例 V=3V=3，基线为 log⁡3≈1.098612\log3\approx1.098612。只有词表确实为 26 个字母加边界、共 27 个 token 时，基线才是 log⁡27≈3.295837\log27\approx3.295837。

均匀基线不是最小可能损失，也不是所有随机初始化的精确损失。 它代表完全均匀的预测。随机且不均匀的 logits 可以给出更高或更低的样本平均 NLL，要看实际预测和数据。

7.6 可选：perplexity 是怎样来的

把平均 NLL 取指数，得到困惑度：

PPL=eLNLL=(∏m=1M1Pxm,ym)1/M. \mathrm{PPL}=e^{L_{\mathrm{NLL}}} =\left(\prod_{m=1}^{M}\frac1{P_{x_m,y_m}}\right)^{1/M}.

所以它是“真实观测概率的倒数”的几何平均。若每一步都在 VV 个候选中均匀分配，PPL 恰好等于 VV，因此常被理解为等效的选择不确定程度。

本例计数模型的 PPL 是 elog⁡3/2=3≈1.732051e^{\log3/2}=\sqrt3\approx1.732051。它可以不是整数，也不代表模型每一步真的只保留这么多个候选。

比较 NLL 或 PPL 时，必须统一测试数据、token 粒度、边界计数和对数口径。字符级与子词级的数字不能直接判断谁更强。

8. 平滑：怎样处理“没见过”

8.1 没见过不等于绝不可能

训练数据中没有 b → a，未平滑模型就令 P(a∣b)=0P(a\mid b)=0。

假如评估一个新名字 ba，就会遇到：

P(𝚋𝚊)=P(b∣.)P(a∣b)P(.∣a)=0. P(\texttt{ba})=P(b\mid .)P(a\mid b)P(.\mid a)=0.

本例前两项都为零；即使只出现一项零，乘积也会归零，NLL 变成无穷大。

这揭示了 MLE 的局限：它只优化已看到的样本。一个小数据集可能没有覆盖未来会遇到的转移。

8.2 Add-alpha 的分子和分母都从计数出发

一个简单办法是在每个格子上加上相同的 α>0\alpha>0，把它当作人为补上的少量计数，再归一化。这些补上的量称为伪计数。

一行有 VV 个格子，总共补了 VαV\alpha，因此：

Pij(α)=Cij+α∑k(Cik+α)=Cij+αni+Vα. \boxed{P^{(\alpha)}_{ij} =\frac{C_{ij}+\alpha}{\sum_k(C_{ik}+\alpha)} =\frac{C_{ij}+\alpha}{n_i+V\alpha}}.

只给分子加数、分母不改，会破坏概率和为 1 的约束。α=1\alpha=1 叫 add-one 或 Laplace smoothing；α\alpha 不必是整数。

对本例取 α=1\alpha=1：

C+1=(131222211),P(1)=(1/53/51/51/31/31/31/21/41/4). C+1= \begin{pmatrix}1&3&1\\2&2&2\\2&1&1\end{pmatrix}, \qquad P^{(1)}= \begin{pmatrix}1/5&3/5&1/5\\1/3&1/3&1/3\\1/2&1/4&1/4\end{pmatrix}.

现在 P(a∣b)=1/4P(a\mid b)=1/4，新名字 ba 的概率是：

P(1)(𝚋𝚊)=15⋅14⋅13=160, P^{(1)}(\texttt{ba})=\frac15\cdot\frac14\cdot\frac13=\frac1{60},

它的每转移平均 NLL 为 log⁡60/3≈1.364782\log60/3\approx1.364782，是有限值。

教材将 add-one 作为入门方法，并提醒它可能把过多概率分给未见事件；α\alpha 应根据验证效果选择。参见 第 3.6.1–3.6.2 节。

8.3 “趋向均匀”不是口号，可以直接拆出来

对有观测的行 ni>0n_i>0：

Cij+αni+Vα=nini+VαCijni+Vαni+Vα1V=λiPijMLE+(1−λi)1V, \begin{aligned} \frac{C_{ij}+\alpha}{n_i+V\alpha} &=\frac{n_i}{n_i+V\alpha}\frac{C_{ij}}{n_i} +\frac{V\alpha}{n_i+V\alpha}\frac1V\\ &=\lambda_i P^{\mathrm{MLE}}_{ij}+(1-\lambda_i)\frac1V, \end{aligned}

其中：

λi=nini+Vα. \lambda_i=\frac{n_i}{n_i+V\alpha}.

所以平滑后的分布，是“这一行的经验分布”与“均匀分布”的加权平均。

  • 这一行数据很多，nin_i 大，经验分布的权重大。
  • 同一行增加 α\alpha，均匀分布的权重增大。
  • α→∞\alpha\to\infty 时，每个格子趋近 1/V1/V。

真正决定平滑强弱的是 VαV\alpha 相对于该行真实样本数 nin_i 的大小，不是孤立地看 α=1\alpha=1 算不算大。

如果整行没有观测，ni=0n_i=0，未平滑的 0/00/0 没有定义。α>0\alpha>0 时，原始平滑公式直接给出 α/(Vα)=1/V\alpha/(V\alpha)=1/V。上面的混合拆分含 Cij/niC_{ij}/n_i，不能直接代入这条空行。

8.4 平滑为什么可能使训练 NLL 变差

未平滑 MLE 已经最小化了同一训练集、同一模型族的 NLL。把概率改向均匀，训练 NLL 因而不会优于原先的最优值，部分行原本就均匀时可以不变。

本例的实际数字是：

α\alpha 训练集 ab, aa 的平均 NLL 留出示例 ba 的平均 NLL
0 0.549306 +∞+\infty
0.1 0.607472 2.266352
1 0.835106 1.364782
10 1.048931 1.131055

这些数由本讲义第 17 节的代码计算，只展示这个极小例子的行为。一个 ba 不足以选择真实任务中的最佳 α\alpha；其他验证集也不保证 α\alpha 越大越好。

平滑是在表达“不要仅凭有限观测就完全排除其他情况”。它解决词表内未见转移，不负责自动处理词表外的新字符；后者还需要预先定义的词表或未知字符策略。

9. 按概率生成：训练、评分和采样各做什么

9.1 采样相当于使用一枚会换规则的骰子

从当前字符 i 出发，取概率表第 i 行。把这一行看作一枚有 VV 个面的骰子，按照对应概率抽下一字符。

当前设为 .
读取 P[当前]，抽一个下一个 token
如果抽到 .，这个名字结束
否则记下这个字符，把它变成新的当前字符
继续

例如使用未平滑表，可能走出：

. → a → a → b → .

这条路径生成 aab，概率为：

1×13×13×1=19. 1\times\frac13\times\frac13\times1=\frac19.

训练集中没有 aab，但它的局部转移都被模型允许。生成新组合的能力由此而来。它不说明模型已经理解名字的语义。

这种“把自己刚生成的结果用作下一步输入”的过程叫自回归生成。

9.2 为什么不是每次 argmax

每次取最大概率的 token 叫贪心选择。在固定模型、固定起点和固定平局规则下，它总会给出同一条路径，还可能陷入循环。

采样保留分布里的其他可能性。PyTorch 可以用 torch.multinomial(row, num_samples=1, generator=g) 抽一个索引；这个名字中的 multinomial 不意味着一次必须生成多个字符。

固定随机种子，是为了在同一环境和相同调用顺序下方便复现实验；它不把采样变成 argmax，也不承诺跨版本、跨设备逐项一致。

9.3 为什么还要有最大长度

代码通常限制最多生成多少字符，避免异常概率表或很长的随机路径让循环一直运行。达到长度上限表示程序截断，不能当作模型自然生成了结束 token。

本 Lab 使用相同边界 token，加平滑后 . → . 也得到正概率，因此可能生成空字符串。这是概率表允许的结果。若产品要求名字非空，可以禁止起始时立即结束并重新归一化，但那是在改变生成规则，评分时也要说明相应约定。

对于有限词表，若每个状态都有严格正的结束概率，最终结束的概率为 1；这仍不保证一次采样不会很长。任意一张“每行和为 1”的表则不自动保证能结束，比如永远 a → a 的表。

9.4 训练不需要先采样名字

训练和评分时，用的是文本里真实的当前字符和真实下一个字符。对于 ab，我们直接评分 . → a、a → b、b → .。

采样时，输入来自模型刚才自己的选择。标准的这个训练目标不需要对随机抽样操作求导；梯度来自模型给真实目标的概率。

第一阶段完成标准：现在应能从 ab, aa 重建两张表，解释 0.5493060.549306 是怎样算出来的，并模拟一次生成。能做到这些，再进入神经版本。

10. 为什么再写一个神经 bigram：把表变成可训练参数

计数模型已经有解析解，为什么还要用梯度下降做一遍？

因为后面要把“给定输入，算出下一字符分布”的内部结构换成能共享特征的神经网络。先在一个已知正确答案的任务上练习张量、loss 和反向传播，可以看清训练过程中每一步的含义。Karpathy 的 makemore 第一课说明把张量运算、训练、采样和损失评估列为核心内容。

10.1 One-hot 是类别选择开关

对 .、a、b 三个类别，one-hot 向量分别是：

e.=(1,0,0),ea=(0,1,0),eb=(0,0,1). e_.=(1,0,0),\quad e_a=(0,1,0),\quad e_b=(0,0,1).

只有当前类别所在位置为 1，其他位置为 0。这种编码保留类别身份，不额外假定字符编号的大小关系。

引入一个可训练矩阵：

W=(w00w01w02w10w11w12w20w21w22). W=\begin{pmatrix} w_{00}&w_{01}&w_{02}\\ w_{10}&w_{11}&w_{12}\\ w_{20}&w_{21}&w_{22} \end{pmatrix}.

与计数表一样，行表示当前字符，列表示候选下一个字符。但这里每个格子是任意实数分数，不是次数，也还不是概率。

10.2 为什么 one_hot @ W 等于选一行

假设当前字符是 a，计算：

eaW=(0,1,0)W=(w10,w11,w12). e_aW=(0,1,0)W=(w_{10},w_{11},w_{12}).

展开第 jj 个输出更容易看清：

zj=∑k=0V−1(ea)kWkj=0W0j+1W1j+0W2j=W1j. z_j=\sum_{k=0}^{V-1}(e_a)_kW_{kj} =0W_{0j}+1W_{1j}+0W_{2j}=W_{1j}.

因此 one-hot 的乘法实际在选中 a 这一行。这一组输出分数 zz 叫 logits。

10.3 一次处理多个样本时的 shape

令 BB 表示一个 batch 的样本数。把 BB 个 one-hot 行堆起来，得到 XX：

X∈ℝB×V,W∈ℝV×V,Z=XW∈ℝB×V. X\in\mathbb R^{B\times V},\quad W\in\mathbb R^{V\times V},\quad Z=XW\in\mathbb R^{B\times V}.

Z 的每一行是一个样本的预测分数，每一列是一个候选下一字符。

实现时可以直接用整数输入查行：

inputs 的 shape：(B,)
weights 的 shape：(V, V)
logits = weights[inputs] 的 shape：(B, V)
targets 的 shape：(B,)

weights[inputs] 与 one-hot 乘法数学上等价，并保留梯度，不需要额外构造大部分为零的输入矩阵。一次 batch 可以重复选中同一行，对这一行的梯度会累加。

11. Softmax：怎样把任意分数变成概率

11.1 参数直接当概率，会遇到约束问题

梯度下降会让 WW 的元素自由变化，可能出现负数，也不会自动让一行之和等于 1。

我们需要一个变换，让任意实数 logits 都得到合法概率，同时便于求导。

第一步，用指数函数把每个分数变成正数：

sj=ezj>0. s_j=e^{z_j}>0.

第二步，除以所有正数的总和：

pj=ezj∑k=0V−1ezk. \boxed{p_j=\frac{e^{z_j}}{\sum_{k=0}^{V-1}e^{z_k}}}.

这就是 softmax。它保证每项为正、和为 1，同时保留分数大小顺序。讲解中有时把 ezje^{z_j} 类比成“可学习的计数”；它们实际上是未归一化正权重，不是真实出现次数。

正值化再归一化并不能唯一推出指数函数。选择指数还带来下面两个很方便的性质，以及第 13 节简洁的梯度。这是一种适合本模型的参数化选择。

11.2 手算一组 logits

为了看见非均匀分布，临时设选中的一行为 z=(0,1,2)z=(0,1,2)，列仍为 .、a、b。

ez=(1,e,e2)≈(1,2.718282,7.389056), e^z=(1,e,e^2)\approx(1,2.718282,7.389056),

总和约为 11.10733811.107338，所以：

p≈(0.090031,0.244728,0.665241). p\approx(0.090031,0.244728,0.665241).

分数为 2 不表示概率为 2；它只是经变换后更偏向 b。

11.3 真正影响概率的是分数差

任取两个类别 j,kj,k：

pjpk=ezjezk=ezj−zk. \frac{p_j}{p_k}=\frac{e^{z_j}}{e^{z_k}}=e^{z_j-z_k}.

对这条式子取 log，得到 log⁡(pj/pk)=zj−zk\log(p_j/p_k)=z_j-z_k。分数差控制概率比；两个类别的 logit 差为 1，它们的概率比就是 ee。

如果给整行加同一个常数 cc：

ezj+c∑kezk+c=ecezjec∑kezk=pj. \frac{e^{z_j+c}}{\sum_k e^{z_k+c}} =\frac{e^c e^{z_j}}{e^c\sum_k e^{z_k}} =p_j.

因此 (0,1,2) 与 (100,101,102) 的 softmax 相同。这个性质也解释了为何权重矩阵的数值未必唯一。

11.4 数值稳定形式从这个性质推出来

直接算很大的 ezje^{z_j} 可能溢出。既然整行加减同一个数不改变结果，就取 m=max⁡kzkm=\max_k z_k，先减最大值：

pj=ezj−m∑kezk−m. p_j=\frac{e^{z_j-m}}{\sum_k e^{z_k-m}}.

现在每个指数的输入都不大于 0，至少一个为 0，避免了指数向上溢出。

计算训练损失时还可以直接在 log 空间处理：

log⁡pj=zj−log⁡∑kezk, \log p_j=z_j-\log\sum_k e^{z_k},

其中稳定的 log-sum-exp 为：

log⁡∑kezk=m+log⁡∑kezk−m. \log\sum_k e^{z_k} =m+\log\sum_k e^{z_k-m}.

这样不必先计算极小概率、再对可能已下溢成零的数取 log。训练代码使用 log_softmax 或 cross_entropy 来完成这些运算。

《动手学深度学习》从分类输出约束引出 softmax，再进入似然和训练目标，适合补读 softmax 回归。

12. 交叉熵为什么等于这里的 NLL

现在有了神经网络输出的概率，还缺训练目标。最自然的做法是继续使用第 7 节：看模型给真实下一个字符的概率。

12.1 把真实类别也写成分布

假设一个样本真实下一个字符是 a。用 qq 表示该样本的目标分布：

q=(0,1,0). q=(0,1,0).

这是“这一次实际观察到了 a”的编码，不是在声称现实中 a 后面只能接某一种字符。

模型预测记为 p=(p.,pa,pb)p=(p_.,p_a,p_b)。交叉熵定义为：

H(q,p)=−∑j=0V−1qjlog⁡pj. H(q,p)=-\sum_{j=0}^{V-1}q_j\log p_j.

代入 one-hot 目标：

H(q,p)=−(0log⁡p.+1log⁡pa+0log⁡pb)=−log⁡pa. H(q,p)=-(0\log p_.+1\log p_a+0\log p_b) =-\log p_a.

因此在本 Lab 的单个正确类别、无类别加权、无 label smoothing设置下，每个样本的交叉熵就是它的 NLL。再对 batch 取平均，就是平均 NLL。

12.2 三种名字对应同一个计算

对真实类别编号为 yy 的样本：

ℓ(z,y)=−log⁡py=−log⁡ezy∑kezk=−zy+log⁡∑kezk. \begin{aligned} \ell(z,y) &=-\log p_y\\ &=-\log\frac{e^{z_y}}{\sum_k e^{z_k}}\\ &=-z_y+\log\sum_k e^{z_k}. \end{aligned}

第一行强调“真实观测的负对数概率”，第二行代入 softmax，第三行是更方便计算和求导的形式。

对 logits (0,1,2)，若真实类别是 a（编号 1）：

ℓ=−1+log⁡(1+e+e2)≈1.407606. \ell=-1+\log(1+e+e^2)\approx1.407606.

虽然 b 的 logit 最大，但这次真实出现的是 a，loss 要取 a 的概率，而不是最大概率。

12.3 PyTorch 调用怎样对应到公式

import torch
import torch.nn.functional as F

logits = torch.tensor([[0.0, 1.0, 2.0]], dtype=torch.float64)
targets = torch.tensor([1], dtype=torch.long)

log_probs = F.log_softmax(logits, dim=1)
manual = -log_probs[torch.arange(len(targets)), targets].mean()
builtin = F.cross_entropy(logits, targets)

print(manual.item(), builtin.item())  # 都约为 1.407606

log_probs[行编号, targets] 为每个样本取出真实目标那一列，再取负平均。torch.arange(B) 产生 0,1,...,B-1，与每行的目标列配对。

F.cross_entropy 的输入应是原始 logits。先做 softmax 再把概率传给它，会把那些概率误当新 logits，计算另一个目标。目标是类别编号时，用 shape (B,) 的整型张量；不必自己构造目标 one-hot。

接口依据 PyTorch cross_entropy 文档，并用本仓库环境中 PyTorch 2.13.0 的函数说明及实际计算核对。

13. 梯度推导：模型到底怎样把错误改回来

这一节是连接 micrograd 与语言建模的关键。我们要从 loss 本身推出梯度方向，而不是记一句“反向传播会提高正确类别概率”。

13.1 从已经展开的单样本损失求导

上一节得到：

ℓ=−zy+log⁡∑kezk. \ell=-z_y+\log\sum_k e^{z_k}.

求它对任意一个 logit zjz_j 的导数。

第一项中，只有当 j=yj=y 时，zyz_y 才会随 zjz_j 变化。因此：

∂(−zy)∂zj=−𝟏[j=y]. \frac{\partial(-z_y)}{\partial z_j}=-\mathbf1[j=y].

符号 𝟏[j=y]\mathbf1[j=y] 叫指示函数：条件成立时为 1，否则为 0。

对第二项，先设 S=∑kezkS=\sum_k e^{z_k}。使用求导的链式法则：

∂log⁡S∂zj=1S∂S∂zj=ezj∑kezk=pj. \frac{\partial\log S}{\partial z_j} =\frac1S\frac{\partial S}{\partial z_j} =\frac{e^{z_j}}{\sum_k e^{z_k}} =p_j.

两项相加：

∂ℓ∂zj=pj−𝟏[j=y]. \boxed{\frac{\partial\ell}{\partial z_j}=p_j-\mathbf1[j=y]}.

写成向量就是 ∇zℓ=p−q\nabla_z\ell=p-q，也就是“预测分布减去这个样本的目标分布”。

13.2 代入数字，检查更新方向

继续用 logits (0,1,2)，真实类别为 a：

p≈(0.090031,0.244728,0.665241),q=(0,1,0), p\approx(0.090031,0.244728,0.665241),\quad q=(0,1,0),

∇zℓ≈(0.090031,−0.755272,0.665241). \nabla_z\ell\approx(0.090031,-0.755272,0.665241).

梯度下降采用：

zjnew=zj−η∂ℓ∂zj, z_j^{\mathrm{new}}=z_j-\eta\frac{\partial\ell}{\partial z_j},

η>0\eta>0 是学习率。对这个单样本、直接优化 logits 的例子：

  • 真实类别 a 的梯度为负，减去负数使它的 logit 上升。
  • 其他类别的梯度为正，更新使它们的 logit 下降。

再做一个一致性检查：所有分量的梯度和为 ∑jpj−1=0\sum_jp_j-1=0。这与“整体平移 logits 不改变概率”相符。

在整个 batch 中，同一行面对不同真实后继时，更新会相互平衡；不能把某一个样本的方向当作所有数据合并后的最终方向。

13.3 梯度怎样传到权重表

一个输入编号为 ii 的样本使用 zj=Wijz_j=W_{ij}，因此它的数据损失只直接影响第 ii 行。

若一个 batch 里有 BB 个样本，且损失取平均：

∂L∂Wij=1B∑m:xm=i(pj(m)−𝟏[ym=j]). \frac{\partial L}{\partial W_{ij}} =\frac1B\sum_{m:x_m=i} \left(p_j^{(m)}-\mathbf1[y_m=j]\right).

求和只遍历输入为 ii 的样本。pj(m)p_j^{(m)} 是第 mm 个样本给类别 jj 的预测概率。

所以：重复输入的梯度要相加，再按 batch 大小平均。未被选中的行没有来自这个 batch 的数据损失梯度。若加了覆盖全表的正则项，其他行仍可能收到正则梯度。

13.4 在完整六个样本上手算一次更新

初始化 W=0W=0，则每行 softmax 都是 (1/3,1/3,1/3)(1/3,1/3,1/3)，初始平均 NLL 是 log⁡3\log3。

对完整训练集，同一行预测相同，于是上面的求和可以收集为：

∂L∂Wij=niPij−CijM. \frac{\partial L}{\partial W_{ij}} =\frac{n_iP_{ij}-C_{ij}}{M}.

本例 M=6M=6，代入计数表：

∇WL=(1/9−2/91/9000−1/91/181/18). \nabla_W L= \begin{pmatrix} 1/9&-2/9&1/9\\ 0&0&0\\ -1/9&1/18&1/18 \end{pmatrix}.

a 行梯度全是零，因为这一行每种后继各出现一次，均匀预测已经符合经验分布。梯度为零在这里是正确结果，不是 autograd 坏了。

取学习率 η=1\eta=1 更新一次后，平均 NLL 从 1.0986121.098612 降为约 1.0107971.010797。第 17 节会用自动微分核对这个结果。

13.5 训练循环中的每一行有什么目的

下面是步骤说明，完整可运行的小实验在第 17 节：

初始化可求导的叶子参数 W
重复若干次：
    清空 W 的旧梯度
    logits = W[inputs]
    loss = cross_entropy(logits, targets)
    loss.backward()
    在 no_grad 中执行 W -= learning_rate * W.grad

清空梯度是因为 PyTorch 默认累加梯度；本练习要用当前这一步的梯度。no_grad 让参数更新不成为下一轮需要反向传播的计算图一部分。

loss.item() 适合记录日志，返回普通数值；用它替代 loss 再反向传播会断开计算图。初始化时也要留意叶子张量，例如先生成和缩放随机数，最后再调用 requires_grad_()。

在这个没有隐藏层的查表模型中，零初始化可以正常学习，上面已经算出非零梯度。不要把“多层网络隐藏单元需要打破对称性”的经验不加区分地套到这里。

14. 计数模型与神经模型究竟是什么关系

14.1 它们在估计相同的条件分布

计数版直接保存 P(j∣i)P(j\mid i)；神经版保存 WijW_{ij}，通过每行 softmax 得到 P(j∣i)P(j\mid i)。

如果一张目标概率表所有元素都严格大于零，可以令：

Wij=log⁡Pij. W_{ij}=\log P_{ij}.

那么：

softmax⁡(Wi)j=elog⁡Pij∑kelog⁡Pik=Pij∑kPik=Pij. \operatorname{softmax}(W_i)_j =\frac{e^{\log P_{ij}}}{\sum_k e^{\log P_{ik}}} =\frac{P_{ij}}{\sum_kP_{ik}} =P_{ij}.

因此神经参数化可以精确表示任意严格正的条件概率表。每行再加任意常数，也表示相同的分布。

若目标表里有零概率，有限 logits 的 softmax 无法精确输出零。要用对应分数相对于其他分数趋向负无穷来逼近。所以对于有零计数的行，神经模型可以不断接近未平滑 MLE 的概率和 loss，但未必存在一组有限权重精确达到边界最优解。

14.2 从梯度为零也能看见计数结果

第 13 节对完整训练集推得：

∂L∂Wij=niPij−CijM. \frac{\partial L}{\partial W_{ij}} =\frac{n_iP_{ij}-C_{ij}}M.

对于 ni>0n_i>0 的行，若能够达到驻点，令梯度为零：

niPij=Cij⇒Pij=Cijni. n_iP_{ij}=C_{ij} \quad\Longrightarrow\quad P_{ij}=\frac{C_{ij}}{n_i}.

这与第 5 节的频率归一化完全一致。对于零计数需要按上一小节的极限情况理解，不能凭这个方程保证有限参数处一定有驻点。

现在“两个模型在学同一个分布”就有了具体含义：它们的未正则化训练目标，对已观察到的输入行，指向同一个经验条件分布。

14.3 为什么训练结果不一定完全相等

有限训练步数、学习率、数值误差，以及正则化都会影响神经模型最终结果。

本 Lab 的可选正则项为：

Ltotal=LNLL+λmean⁡(W2)=LNLL+λV2∑i,jWij2. L_{\mathrm{total}} =L_{\mathrm{NLL}}+\lambda\operatorname{mean}(W^2) =L_{\mathrm{NLL}}+\frac{\lambda}{V^2}\sum_{i,j}W_{ij}^2.

λ≥0\lambda\ge0 控制惩罚强度。它额外产生 2λWij/V22\lambda W_{ij}/V^2 的梯度，抑制过大的权重绝对值。强正则倾向于让 logits 接近零，此时 softmax 接近均匀。

但 L2 权重正则、add-alpha 伪计数、交叉熵接口中的 label smoothing 是不同操作。它们可能都让预测没那么极端，不能据此说 λ=0.01\lambda=0.01 等价于某个确定的 α\alpha。要比较正则强度，需实际评估。

比较模型时，分别报告纯 NLL 与加入正则的训练 objective。不能把含正则项的 total loss 直接拿去和计数版 NLL 比。

14.4 下一课真正要增加什么

当前两个模型都只看前一个字符，并且每一行单独学习，没有通过共享隐藏特征联系不同输入字符。

若希望区分 ba 和 aa，必须让模型看到更多上下文。直接把所有更长上下文建表会迅速增加表的规模；后续 embedding 和 MLP 会让不同上下文利用共享的参数与特征。

所以这里学习神经 bigram 的价值，是理解可微训练接口，并为扩展模型做准备。相同输入信息与相同自由概率表，并不会因为换成梯度下降而自动得到更强的语言理解能力。

15. 评估与排错：如何知道真的学会了

15.1 训练 NLL 回答的不是泛化问题

训练 NLL 衡量模型是否拟合已见数据。验证集（dev/validation set）衡量在未参与参数拟合的数据上表现如何；测试集留到模型与超参数确定之后再做最终评估。

在实际名字数据上，应当先按完整名字划分，再从各部分分别构造转移。若先展开转移再随机拆分，同一个名字的内容可能同时进入训练和验证，难以评价对新名字的泛化。

如果目标是评估从未见过的名字拼写，完全相同的重复名字也应按组分到同一侧；否则你评估的是包含重复名字的同分布数据，结论要对应这个目标。

先固定词表及未知字符策略，再仅用训练数据计数或更新权重。验证集用于选择 α\alpha、正则强度和训练轮次，不往训练计数里补数；测试集不反复用来调参。

import math
import torch
import torch.nn.functional as F

# 本讲义固定的六次转移。行、列顺序为 .、a、b。
C = torch.tensor([[0, 2, 0], [1, 1, 1], [1, 0, 0]], dtype=torch.float64)
x = torch.tensor([0, 1, 2, 0, 1, 1], dtype=torch.long)
y = torch.tensor([1, 2, 0, 1, 1, 0], dtype=torch.long)
V = 3

print("uniform NLL:", math.log(V))
for alpha in (0.0, 0.1, 1.0, 10.0):
    counts = C + alpha
    P = counts / counts.sum(dim=1, keepdim=True)
    train_nll = -P[x, y].log().mean()
    # 留出示例 ba 的三条边：.→b、b→a、a→.
    dev_nll = -P[[0, 2, 1], [2, 1, 0]].log().mean()
    print(f"alpha={alpha:4.1f} train={train_nll.item():.6f} ba={dev_nll.item():.6f}")

# one-hot 乘法和整数查行是否相同？
W_demo = torch.arange(9, dtype=torch.float64).reshape(V, V)
X = F.one_hot(x, num_classes=V).to(torch.float64)
print("one-hot == indexing:", torch.equal(X @ W_demo, W_demo[x]))

# 对一个样本核对 CE = NLL，以及 d(loss)/d(logits) = p - q。

smoothed = (C + 1) / (C + 1).sum(1, keepdim=True)
print("softmax(log(P)) = P:", torch.allclose(smoothed.log().softmax(1), smoothed))

附录 A. 任意计数下最大似然估计的完整推导

这一部分解释第 5 节的结论为何对任意词表与计数成立。需要基本求导；第一次阅读可以在理解手算例子后暂时跳过。

A.1 先说明优化变量和约束

固定当前 token 为某个 ii，把这一行简写为 pj=P(j∣i)p_j=P(j\mid i)，计数简写为 cj=Cijc_j=C_{ij}，行总数为 n=∑jcj>0n=\sum_jc_j>0。

要找的是 VV 个概率 pjp_j，它们满足：

pj≥0,∑jpj=1. p_j\ge0,\qquad \sum_jp_j=1.

先假设每个 cj>0c_j>0，这样最优解必须在 pj>0p_j>0 的内部；否则某个真实观测的概率为零，会使似然为零。

A.2 相同结果出现多次，概率就出现多次

第 jj 种后继出现 cjc_j 次，因此该行的似然可以合并成：

ℒi=∏jpjcj. \mathcal L_i=\prod_jp_j^{c_j}.

这是把固定观测序列中的相同因子收集到一起。若从“只关心各类别计数”的多项分布形式开始，还会出现一个与 pp 无关的组合系数，它不改变最大值的位置。

取自然对数：

log⁡ℒi=∑jcjlog⁡pj. \log\mathcal L_i=\sum_jc_j\log p_j.

我们要最大化这个函数，同时保持概率和等于 1。

A.3 为什么需要处理约束

如果忽略 ∑jpj=1\sum_jp_j=1，我们会想把所有观测类别的概率都调到 1，这是不合法的。

可以用 Lagrange 乘子把约束加入目标。引入一个辅助数 μ\mu：

Φ(p,μ)=∑jcjlog⁡pj+μ(1−∑jpj). \Phi(p,\mu)=\sum_jc_j\log p_j+\mu\left(1-\sum_jp_j\right).

乘子法的作用是在总概率预算固定为 1 的条件下寻找驻点。对 μ\mu 求导为零会恢复约束 1−∑jpj=01-\sum_jp_j=0。

对每个 pjp_j 求导并令其为零：

∂Φ∂pj=cjpj−μ=0. \frac{\partial\Phi}{\partial p_j}=\frac{c_j}{p_j}-\mu=0.

移项可得：

pj=cjμ. p_j=\frac{c_j}{\mu}.

把所有 pjp_j 相加，并使用总和为 1 的条件：

1=∑jpj=∑jcjμ=nμ⇒μ=n. 1=\sum_jp_j=\frac{\sum_jc_j}{\mu}=\frac n\mu \quad\Longrightarrow\quad\mu=n.

代回去：

pj=cjn. \boxed{p_j=\frac{c_j}{n}}.

由于 log\log 是凹函数，非负计数加权的 log-likelihood 也是凹函数，概率约束集合是凸的。所有计数为正时，上面找到的是唯一的概率最优解，而不是任意局部点。

A.4 零计数和整行空缺怎样处理

如果某个 cj=0c_j=0，这一类没有被观察到。只要该行有其他真实观测，给零计数类别分配正概率，就会占用本可以分给已观察类别的概率预算。因此未平滑 MLE 把这类概率设为零。

对计数为正的类别重复上面的推导，仍得到 pj=cj/np_j=c_j/n。不能直接在 pj=0p_j=0 处机械地使用 cj/pjc_j/p_j 的内部求导步骤。

在合并的 log-likelihood 公式中，零计数项按约定贡献 0。数值代码直接计算 0 * log(0) 可能得到 NaN，所以实际 NLL 最容易通过逐条真实转移索引计算，或显式屏蔽零计数项。

若整行 n=0n=0，没有任何数据项依赖这行概率，每种合法分布都同样符合观测，MLE 无法唯一决定该行。平滑或其他先验假设才会给它一个具体分布。

A.5 为什么可以一行一行求

整份数据的 log-likelihood 可以写成：

log⁡ℒ=∑i∑jCijlog⁡Pij. \log\mathcal L=\sum_i\sum_j C_{ij}\log P_{ij}.

每一行只有自己那一行的概率变量，并且每一行各有“和为 1”的约束。不同的行没有共享参数，因此可以分别优化。

这也说明后续引入共享神经特征后，为何不再能简单地独立归一化每一行就完成所有训练：不同输入的预测会通过共同参数相互联系。
