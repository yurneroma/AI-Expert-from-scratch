## 三层结构：愿景 → 年度 → 合同

```
Layer 1  愿景（3-5 年，不变）   : 成为 LLM 训练领域的专家 + 有公认的公开作品和影响力
Layer 2  年度（每年定一次）     : Year 1 = 打穿"从零实现 → 训练系统 → 后训练"全链路
Layer 3  合同（每 14 天细化）   : 唯一需要每天看的东西，见下方"当前合同"
```

**分层的意义**: 愿景层保证不迷失——琐事打断的是某一天，打断不了 3 年的方向。合同层保证可落地——每天打开只看一张表。中间不需要更多文档。

## 运行规则（全部规则就这 5 条）

1. **每天只看"当前合同"那张表**，其他部分两周看一次
2. **每天一个 commit**，哪怕是失败的实验；公开产出硬约束：每两周一篇博客
3. **每 14 天验收**: ≥10/14 天有有效 commit → 续签并细化下一周期；<10 天 → 停止规划，先解决执行障碍
4. **理解 > 进度**: 卡住就慢下来，但 commit 不能停；改路线可以，当天的任务不能弃
5. **被琐事打断的一天不算失败**，第二天回到表上继续即可——愿景在 Layer 1，丢不了
